# O player lê o HLS direto do storage, com só a pasta HLS pública

O navegador baixa a playlist e os segmentos HLS direto do storage S3, sem passar pela API. No bucket, só `assets/*/hls/*` tem leitura anônima (política aplicada pelo `storage-init`); o arquivo original em `assets/*/source/` continua privado. O CORS do bucket libera o dashboard local. A API devolve a URL da playlist montada com `S3_PUBLIC_URL`. A alternativa de URLs assinadas foi descartada porque cada segmento listado na playlist precisaria da própria assinatura, o que exige reescrever a playlist a cada requisição. Passar os arquivos pela API também foi descartado: ela viraria um proxy de vídeo sem necessidade. Em produção, a mesma pasta pública fica atrás de uma CDN; se for preciso proteger o conteúdo, a decisão é revista junto com autenticação.
