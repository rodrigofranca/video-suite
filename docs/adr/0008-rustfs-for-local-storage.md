# RustFS como storage S3 local (substitui o MinIO)

O MinIO foi a escolha original para o storage local, mas a imagem `minio/minio` não está mais disponível no Docker Hub (o repositório retornava 404 em 2026-11-07), o que quebrava `make up`. Testamos o RustFS 1.0.4 (licença Apache-2.0, API S3, console web) com o que o projeto precisa: criação de bucket, upload multipart de 28 MB, política de leitura pública por prefixo e CORS via `PutBucketCors`; tudo funcionou. Garage e SeaweedFS também foram considerados, mas exigem mais configuração inicial (layout de cluster no Garage, arquivo de identidades no SeaweedFS). O bucket e o CORS são criados pelo serviço `storage-init` com a AWS CLI, usando chamadas S3 padrão. Como o código só fala S3 (ADR 0006), trocar de servidor no futuro é mudar apenas o `docker-compose.yml`.
