# O worker de IA é Python, lê uma fila própria e espelha os contratos do Go

Concretiza a ADR 0007. A transcrição roda em `apps/ai-worker`, um worker Python com faster-whisper, escolhido em vez de chamar o whisper.cpp pelo worker Go ou de usar uma API na nuvem: é gratuito, privado, roda em CPU e abre caminho para os modelos de visão do Milestone 3. Cada tipo de worker lê o próprio stream: `jobs` (worker Go, FFmpeg) e `jobs:ai` (worker Python); `jobcontracts.StreamFor` diz para onde cada tipo de job vai, e API e workers enfileiram por ela. A alternativa — um único stream com dois consumer groups — entregaria toda mensagem aos dois workers, e cada um precisaria ignorar metade delas. O worker Python reimplementa o mesmo ciclo de vida do Go (status no PostgreSQL, logs em `job_logs`, progresso, limite de 30 minutos, encadeamento, ack mesmo em falha, retomada após queda). Para os contratos não divergirem, o Go grava `packages/job-contracts/testdata/contracts.json` (tipos, ordem do pipeline, streams, campos e exemplos de entrada) e um teste de cada lado confere esse arquivo: mudar um lado sem o outro quebra a suíte de testes.
